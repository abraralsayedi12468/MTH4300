# MTH 4300 – Algorithms, Computers, and Programming II

This repository documents my coursework, programming exercises, and progress in **MTH 4300: Algorithms, Computers, and Programming II** at **Baruch College**.

## About the Course

MTH 4300 is a continuation of MTH 3300 and introduces more advanced programming and computer science concepts using **C++**. The course focuses on understanding how programs manage data and memory while developing reliable, reusable, and well-structured solutions to increasingly difficult problems.

According to Baruch College’s course description, MTH 4300 covers advanced topics such as pointers, dynamic memory allocation, class implementation, inheritance, polymorphism, abstract data types, data structures, and object-oriented programming.

Throughout the semester, the course will cover topics including:

- C++ syntax and program structure
- Variables, expressions, and data types
- Conditional statements and loops
- Functions and return values
- Pass by value, reference, and pointer
- The `const` keyword
- Memory addresses and pointers
- Pointer arithmetic and null-pointer safety
- Arrays and multidimensional arrays
- Stack and heap memory
- Dynamic memory allocation using `new` and `delete`
- References and memory management
- Linked lists and other pointer-based structures
- Trees and more advanced data structures
- Classes and objects
- Constructors and class implementation
- Inheritance and polymorphism
- Abstract data types
- Object-oriented programming
- Algorithm development and problem-solving
- More advanced coding and LeetCode-style problems
- Writing reliable, maintainable, and reusable C++ programs
